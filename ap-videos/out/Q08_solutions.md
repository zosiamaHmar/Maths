# Question 8 — Finding a term from Sₙ

##  In an AP the sum of first n terms is  {3n²|2} + {13n|2}.  Find its 25th term.

- **We use: the 25th term is S₂₅ minus S₂₄**
  - `a₂₅ = S₂₅ − S₂₄`
- **First find S₂₅. Put n = 25**
  - `S₂₅ = {3(25)²|2} + {13(25)|2}`
  - `= {3(625)|2} + {325|2}`
  - `= {1875|2} + {325|2}`
  - `= {2200|2} = 1100`
- **Now find S₂₄. Put n = 24**
  - `S₂₄ = {3(24)²|2} + {13(24)|2}`
  - `= {3(576)|2} + {312|2}`
  - `= {1728|2} + {156 × 2|2}`
  - `= 864 + 156 = 1020`
- **Subtract**
  - `a₂₅ = 1100 − 1020`
  - `a₂₅ = 80`

**Answer:** `a₂₅ = 80`

- *Check — Quick check using a general formula: aₙ = Sₙ − Sₙ₋₁ = 3n + 5*: `a₂₅ = 3(25) + 5 = 75 + 5 = 80`
