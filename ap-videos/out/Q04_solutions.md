# Question 4 — How many terms?

## (i) How many terms of the AP 3, 5, 7, 9, … must be added to get the sum 120?

- **Write down what we know**
  - `a = 3,   d = 5 − 3 = 2,   Sₙ = 120`
- **Use the sum formula**
  - `Sₙ = {n|2} [2a + (n − 1)d]`
  - `120 = {n|2} [2(3) + (n − 1)(2)]`
- **Simplify inside the bracket**
  - `120 = {n|2} [6 + 2n − 2]`
  - `120 = {n|2} (2n + 4)`
- **Cancel the 2**
  - `120 = n (n + 2)`
  - `120 = n² + 2n`
- **Make one side zero**
  - `n² + 2n − 120 = 0`
- **Factorise. Two numbers that multiply to −120 and add to +2 are +12 and −10**
  - `n² + 12n − 10n − 120 = 0`
  - `n (n + 12) − 10 (n + 12) = 0`
  - `(n + 12)(n − 10) = 0`
- **Set each bracket to zero**
  - `n = −12   or   n = 10`
- **A number of terms cannot be negative, so reject −12**
  - `n = 10`

**Answer:** `10 terms`

- *Check — Quick check*: `a₁₀ = 3 + 9(2) = 21`; `S₁₀ = 5 × (3 + 21) = 5 × 24 = 120`

## (ii) How many terms of the AP 63, 60, 57, … must be added so that their sum is 693? Explain the double answer.

- **Write down what we know**
  - `a = 63,   d = 60 − 63 = −3,   Sₙ = 693`
- **Use the sum formula**
  - `693 = {n|2} [2(63) + (n − 1)(−3)]`
- **Simplify inside the bracket**
  - `693 = {n|2} [126 − 3n + 3]`
  - `693 = {n|2} (129 − 3n)`
- **Multiply both sides by 2**
  - `1386 = n (129 − 3n)`
  - `1386 = 129n − 3n²`
- **Make one side zero**
  - `3n² − 129n + 1386 = 0`
- **Divide every term by 3**
  - `n² − 43n + 462 = 0`
- **Factorise. Two numbers that multiply to 462 and add to −43 are −21 and −22**
  - `n² − 21n − 22n + 462 = 0`
  - `n (n − 21) − 22 (n − 21) = 0`
  - `(n − 21)(n − 22) = 0`
- **Both answers are positive whole numbers, so both are valid**
  - `n = 21   or   n = 22`
- **Why two answers? Find the 22nd term**
  - `a₂₂ = 63 + 21(−3) = 63 − 63`
  - `a₂₂ = 0`
- **The 22nd term is zero, and adding zero changes nothing. So the sum of 21 terms and the sum of 22 terms are the same**
  - `S₂₁ = S₂₂ + 0 = 693`

**Answer:** `n = 21 or n = 22`

- *Check — Quick check of 21 terms*: `a₂₁ = 63 + 20(−3) = 3`; `S₂₁ = {21|2} (63 + 3) = {21|2} × 66 = 693`

## (iii) How many terms of the series 54, 51, 48, … be taken so that their sum is 513? Explain the double answer.

- **Write down what we know**
  - `a = 54,   d = 51 − 54 = −3,   Sₙ = 513`
- **Use the sum formula**
  - `513 = {n|2} [2(54) + (n − 1)(−3)]`
- **Simplify inside the bracket**
  - `513 = {n|2} [108 − 3n + 3]`
  - `513 = {n|2} (111 − 3n)`
- **Multiply both sides by 2**
  - `1026 = n (111 − 3n)`
  - `1026 = 111n − 3n²`
- **Make one side zero**
  - `3n² − 111n + 1026 = 0`
- **Divide every term by 3**
  - `n² − 37n + 342 = 0`
- **Factorise. Two numbers that multiply to 342 and add to −37 are −18 and −19**
  - `n² − 18n − 19n + 342 = 0`
  - `n (n − 18) − 19 (n − 18) = 0`
  - `(n − 18)(n − 19) = 0`
- **Both are valid whole numbers**
  - `n = 18   or   n = 19`
- **Why two answers? Find the 19th term**
  - `a₁₉ = 54 + 18(−3) = 54 − 54`
  - `a₁₉ = 0`
- **The 19th term is zero, so adding it does not change the sum. 18 terms and 19 terms give the same total**
  - `S₁₈ = S₁₉ = 513`

**Answer:** `n = 18 or n = 19`

- *Check — Quick check of 18 terms*: `a₁₈ = 54 + 17(−3) = 3`; `S₁₈ = 9 × (54 + 3) = 9 × 57 = 513`
