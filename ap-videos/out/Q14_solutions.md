# Question 14 — Finding n and d

##  In an AP the first term is 22, the nth term is −11 and the sum to n terms is 66. Find n and d.

- **Write down what we know**
  - `a = 22,   l = aₙ = −11,   Sₙ = 66`
- **Use the second sum formula**
  - `Sₙ = {n|2} (a + l)`
  - `66 = {n|2} (22 + (−11))`
- **Add inside the bracket**
  - `66 = {n|2} × 11`
- **Multiply both sides by 2**
  - `132 = 11n`
- **Divide both sides by 11**
  - `n = {132|11} = 12`
- **Now find d using the nth term formula**
  - `aₙ = a + (n − 1)d`
  - `−11 = 22 + (12 − 1)d`
  - `−11 = 22 + 11d`
- **Subtract 22 from both sides**
  - `−11 − 22 = 11d`
  - `−33 = 11d`
- **Divide by 11**
  - `d = −3`

**Answer:** `n = 12,   d = −3`

- *Check — Quick check: the 12th term is 22 + 11(−3) = −11, and the sum is*: `S₁₂ = 6 (22 − 11) = 6 × 11 = 66 ✓`
