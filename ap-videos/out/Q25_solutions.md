# Question 25 — Seven cash prizes

##  ₹700 is to be used to give seven cash prizes to students. Each prize is ₹20 less than the one before it. Find the value of each prize.

- **The prizes make an AP. Seven prizes, ₹20 less each time, total ₹700**
  - `n = 7,   d = −20,   S₇ = 700`
- **Use the sum formula**
  - `700 = {7|2} [2a + (7 − 1)(−20)]`
  - `700 = {7|2} [2a − 120]`
- **Multiply both sides by 2, then divide by 7**
  - `1400 = 7 (2a − 120)`
  - `200 = 2a − 120`
- **Add 120 to both sides**
  - `320 = 2a`
- **Divide by 2**
  - `a = 160`
- **The first prize is ₹160. Subtract 20 each time to get the others**
  - `160, 140, 120, 100, 80, 60, 40`

**Answer:** `₹160, ₹140, ₹120, ₹100, ₹80, ₹60, ₹40`

- *Check — Quick check: add all seven prizes*: `160 + 140 + 120 + 100 + 80 + 60 + 40 = 700 ✓`
