# Question 2 — Sum when the last term is known

## (i) Find the sum  −5 + (−8) + (−11) + … + (−230).

- **First find the common difference**
  - `d = −8 − (−5) = −8 + 5 = −3`
- **Write down what we know**
  - `a = −5,   d = −3,   l = −230`
- **To find how many terms, use the nth term formula**
  - `aₙ = a + (n − 1)d`
- **The last term is the nth term, so put it in**
  - `−230 = −5 + (n − 1)(−3)`
- **Move a to the other side by subtracting**
  - `−230 − (−5) = (n − 1)(−3)`
  - `−225 = (n − 1)(−3)`
- **Divide both sides by d**
  - `n − 1 = {−225|−3} = 75`
- **Add 1 to both sides**
  - `n = 75 + 1 = 76`
- **Now we know the first and last term, so use the second sum formula**
  - `Sₙ = {n|2} (a + l)`
- **Put the numbers in**
  - `S₇₆ = {76|2} (−5 + (−230))`
- **Add the two terms**
  - `= 38 × (−235)`
- **Multiply**
  - `= −8930`

**Answer:** `Sum = −8930`

- *Check — Quick check using the other formula*: `S₇₆ = 38 × (−5 − 230) = 38 × (−235) = −8930`

## (ii) Find the sum  7 + 10½ + 14 + … + 84.

- **The second term 10½ is the same as 10.5. First find the common difference**
  - `d = 10.5 − 7 = 3.5`
- **Write down what we know**
  - `a = 7,   d = 3.5,   l = 84`
- **To find how many terms, use the nth term formula**
  - `aₙ = a + (n − 1)d`
- **The last term is the nth term, so put it in**
  - `84 = 7 + (n − 1)(3.5)`
- **Subtract 7 from 84**
  - `84 − 7 = 3.5 (n − 1)`
  - `77 = 3.5 (n − 1)`
- **Divide both sides by 3.5**
  - `n − 1 = {77|3.5} = 22`
- **Add 1 to both sides**
  - `n = 23`
- **Now use the second sum formula**
  - `Sₙ = {n|2} (a + l)`
- **Put the numbers in**
  - `S₂₃ = {23|2} (7 + 84)`
- **Add the two terms**
  - `= {23|2} × 91`
- **Multiply 23 by 91, then halve it**
  - `= {2093|2}`
  - `= 1046.5`

**Answer:** `Sum = 1046.5  (= {2093|2})`

- *Check — Quick check: 23 × 91*: `23 × 91 = 23 × 90 + 23 = 2070 + 23 = 2093`; `2093 ÷ 2 = 1046.5`

## (iii) Find the sum  25 + 28 + 31 + … + 100.

- **Find the common difference**
  - `d = 28 − 25 = 3`
- **Write down what we know**
  - `a = 25,   d = 3,   l = 100`
- **To find how many terms, use the nth term formula**
  - `aₙ = a + (n − 1)d`
- **The last term is the nth term, so put it in**
  - `100 = 25 + (n − 1)(3)`
- **Move a to the other side by subtracting**
  - `100 − 25 = (n − 1)(3)`
  - `75 = (n − 1)(3)`
- **Divide both sides by d**
  - `n − 1 = {75|3} = 25`
- **Add 1 to both sides**
  - `n = 25 + 1 = 26`
- **Now we know the first and last term, so use the second sum formula**
  - `Sₙ = {n|2} (a + l)`
- **Put the numbers in**
  - `S₂₆ = {26|2} (25 + 100)`
- **Add the two terms**
  - `= 13 × 125`
- **Multiply**
  - `= 1625`

**Answer:** `Sum = 1625`

- *Check — Quick check*: `13 × 125 = 13 × 100 + 13 × 25 = 1300 + 325 = 1625`
