# Question 20 — Common difference from Sₚ

##  If the sum of the first p terms of an AP is ap² + bp, find the common difference.

- **Find the first term: put p = 1**
  - `S₁ = a(1)² + b(1) = a + b`
  - `first term = a + b`
- **Find the sum of 2 terms: put p = 2**
  - `S₂ = a(2)² + b(2) = 4a + 2b`
- **The second term is S two minus S one**
  - `second term = (4a + 2b) − (a + b)`
  - `= 4a + 2b − a − b`
  - `= 3a + b`
- **Common difference is the second term minus the first term**
  - `d = (3a + b) − (a + b)`
  - `= 3a + b − a − b`
- **b cancels, and 3a minus a is 2a**
  - `d = 2a`

**Answer:** `d = 2a`

- *Check — Quick check with the general formula*: `aₚ = Sₚ − Sₚ₋₁ = 2ap − a + b,   so the terms rise by 2a each time ✓`
