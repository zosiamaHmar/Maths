# Question 15 — Finding n and d

##  In an AP the first term is 8, the nth term is 33 and the sum to n terms is 123. Find n and d.

- **Write down what we know**
  - `a = 8,   l = aₙ = 33,   Sₙ = 123`
- **Use the second sum formula**
  - `Sₙ = {n|2} (a + l)`
  - `123 = {n|2} (8 + 33)`
- **Add inside the bracket**
  - `123 = {n|2} × 41`
- **Multiply both sides by 2**
  - `246 = 41n`
- **Divide both sides by 41**
  - `n = {246|41} = 6`
- **Now find d using the nth term formula**
  - `aₙ = a + (n − 1)d`
  - `33 = 8 + (6 − 1)d`
  - `33 = 8 + 5d`
- **Subtract 8 from both sides**
  - `33 − 8 = 5d`
  - `25 = 5d`
- **Divide by 5**
  - `d = 5`

**Answer:** `n = 6,   d = 5`

- *Check — Quick check: the terms are 8, 13, 18, 23, 28, 33*: `8 + 13 + 18 + 23 + 28 + 33 = 123 ✓`
